# Emberwake concept and art direction

Version 2 • 13 October 2026 • Active preproduction baseline

Emberwake is a portrait 1v1 naval card-deployment game inspired by Clash Royale's flow and the supplied video's miniature ships. Build an eight-card fleet deck, spend regenerating Supply, deploy autonomous ship classes into two channels and destroy the enemy harbor. Start with three minutes of regulation plus up to two minutes of overtime; the user clarified that duration is flexible. Photon Fusion with dedicated authority is the proposed online foundation.

## Status and precedence

V2 replaces the v1 controlled-ship PvE loop. No playable Unity build, Tripo mesh, Photon account configuration or latency benchmark has been created in this phase. Renders are AI targets, not engine screenshots. The gameplay and commercial values are proposed tuning; research observations are cited separately.

For conflicts, follow FLEET-DUEL-V2.md for rules, Production/PHOTON-NETWORKING.md for networking, and Production/FLEET-DUEL-PRODUCTION-V2.md for art/asset corrections. Use the v2 fleet board for class silhouettes and battle image for composition. V1 palette principles and the isolated Cutter remain useful where compatible. Incidental AI counters, geometry or labels never override data definitions.

All five renders were generated using the built-in image generation tool. Exact prompts are saved in [Prompts](Prompts/). Every selected image is stored in this project. The next milestone is a bot duel and two-client Photon deployment spike, followed by measured device/network validation.
